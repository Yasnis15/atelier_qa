# cas-03 - Validation des champs obligatoires vides

## Titre
Soumission du formulaire de connexion avec les champs vides.

## Préconditions
- L'utilisateur est sur la page de connexion.

## Étapes d'exécution
1. Laisser les champs "Email" et "Mot de passe" vides.
2. Cliquer sur le bouton "Se connecter".

## Résultat attendu
- Le formulaire n'est pas soumis.
- Les champs s'affichent en surbrillance rouge avec la mention "Champ obligatoire".
- Tous les champs sont à jour
